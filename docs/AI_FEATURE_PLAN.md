# «Твоё имя на холме» — план и смета

Вирусная ИИ-фича для TamirlanOS по мотивам кампании _Face Your Fate_ (The Odyssey, Nolan).
Документ: что строим, сколько стоит, как не слить бюджет.

Дата: июль 2026.

---

## 1. Идея

Посетитель вводит своё имя (или делает селфи) и получает **персональные обои TamirlanOS** — тот
самый зелёный холм с именем, выстриженным в траве. Обои сразу становятся фоном его сессии,
их можно скачать и запостить.

**Почему именно это, а не «стань греческим воином»:** артефакт, которым делится пользователь,
несёт твою фирменную эстетику. Каждый репост — реклама твоего визуального языка, а не абстрактная
красивая картинка. Механика Нолана даёт вирусность; наша версия добавляет к ней брендинг.

### Воронка

```
Заходит на сайт → видит обои TAMIRLAN → «а можно со мной?»
   → вводит имя → 3 сек → его обои → скачивает / ставит фоном → постит
   → в кадре TamirlanOS → приходят новые люди
```

Ключевая метрика: **доля посетителей, нажавших кнопку** (цель > 25%),
и **доля скачавших результат** (цель > 60% от нажавших).

## 2. Две реализации

|                | Этап 1 — Canvas/WebGL                                            | Этап 2 — ИИ-генерация                            |
| -------------- | ---------------------------------------------------------------- | ------------------------------------------------ |
| Как работает   | Текст на канвасе + карта смещения по текстуре травы, тень, блики | Модель дорисовывает надпись/лицо фотореалистично |
| Скорость       | Мгновенно (< 100 мс)                                             | 3–10 секунд                                      |
| Стоимость      | **0 ₽**                                                          | ~4–13 ¢ за картинку                              |
| Инфраструктура | Ничего, статика                                                  | Cloudflare Worker + ключ API                     |
| Риск           | Нет                                                              | Слив бюджета, модерация контента                 |
| Качество       | ~90% эффекта                                                     | 100% + вариативность                             |

**Рекомендация: строить этап 1, измерить конверсию, и только потом решать про этап 2.**
Если кнопку жмут 5% — платить за генерацию незачем. Если 40% — вкладываться осмысленно.

## 3. Архитектура

### Этап 1 (без сервера)

```
components/apps/wallpaper-studio/
  WallpaperStudioApp.tsx   — окно: поле имени, превью, кнопки
core/wallpaper/
  engrave.ts               — отрисовка надписи в траве (чистая логика, без React)
stores/
  desktop-store.ts         — уже есть: добавить customWallpaper
```

Техника надписи: рисуем текст в offscreen-канвас → размываем в карту высот → смещаем пиксели
исходной травы по градиенту этой карты → накладываем затемнение по «глубине среза» и лёгкий
жёлто-зелёный блик по краю. Результат — ощущение, что траву действительно выстригли.

Готовые обои сохраняем в IndexedDB (механика уже есть в `core/photos/photo-db.ts`), чтобы
фон пережил перезагрузку.

### Этап 2 (с ИИ)

```
Браузер → Cloudflare Worker (ключ живёт здесь) → Gemini / fal.ai → картинка → браузер
              ↑
        KV: счётчик по IP + дневной потолок
```

Ключ API **никогда** не попадает в браузер. Worker проверяет лимиты, зовёт модель, отдаёт результат.

### Защита бюджета — обязательна

1. **Дневной потолок**: счётчик в KV, при достижении N генераций фича отвечает «Агент отдыхает,
   загляни завтра». N ставим из расчёта комфортного расхода: 100/день ≈ $45/мес на Flux Schnell.
2. **Лимит по IP**: 3 генерации в сутки с адреса. Хватает поиграться, не хватает майнить.
3. **Turnstile** (капча Cloudflare, бесплатно) перед вызовом — отсекает ботов.
4. **Кеш по нормализованному имени**: «Айгерим» и «айгерим» — одна картинка из KV, не два вызова.
   На популярных именах экономит десятки процентов.
5. **Алерт на почту** при 80% дневного лимита.

## 5. Риски

| Риск                           | Вероятность | Что делаем                                                                |
| ------------------------------ | ----------- | ------------------------------------------------------------------------- |
| Слив бюджета                   | Средняя     | Потолок + лимит по IP + Turnstile (п. 4)                                  |
| Оскорбительные имена в обоях   | **Высокая** | Стоп-лист + фильтр длины/алфавита; для селфи — модерация модели           |
| Загрузка чужих лиц             | Средняя     | Не храним изображения; обработка и отдача без записи на диск              |
| Модель рисует текст с ошибками | Высокая     | Текст накладываем сами канвасом поверх ИИ-фона — не доверяем модели буквы |
| Медленно на телефоне           | Низкая      | Этап 1 работает локально и мгновенно                                      |

Отдельно про приватность: если делаем селфи-версию, нужна явная строка «фото не сохраняется,
обрабатывается и удаляется» — и это должно быть правдой в коде.

## 6. Этапы

**Этап 1 — 1–2 вечера, 0 ₽**
Окно «Обои», движок гравировки, сохранение в IndexedDB, кнопка «Скачать», подстановка в фон.
Плюс кнопка «Поделиться» с готовым текстом и ссылкой.

**Замер — 2 недели**
Считаем клики и скачивания (Cloudflare Web Analytics, бесплатно, без кук).

**Этап 2 — 1–2 вечера + расходы на API**
Worker с лимитами, Turnstile, кеш в KV, XP-диалог прогресса «Обработка изображения…».
Начинаем с Flux 2 Schnell, при необходимости поднимаем до Gemini Flash Image.

**Этап 3 — по желанию**
Селфи → аватар в стиле XP → экран входа с лицом посетителя.
